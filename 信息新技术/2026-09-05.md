## 一、今日知识点

### 1. Kubernetes：容器编排
Kubernetes（K8s）用于自动化部署、扩缩容和管理容器化应用。

| 概念 | 核心作用 |
|---|---|
| Pod | 常见最小调度单元，可包含一个或多个容器 |
| Deployment | 管理应用副本和滚动更新 |
| Service | 为一组 Pod 提供稳定访问入口与服务发现 |
| Node | 承载工作负载的节点 |
| Control Plane | 负责集群控制、调度与状态管理 |

📌 **国网考点：** 容器解决应用封装和运行，Kubernetes 重点解决大量容器的编排和管理。

⚠️ **易错提醒：** Pod 不等于单个容器。

### 2. CAP 与 BASE
CAP 描述分布式系统的重要权衡：C 为一致性，A 为可用性，P 为分区容错性。发生网络分区时，系统通常需要在一致性与可用性之间权衡。

BASE 常概括为：Basically Available（基本可用）、Soft State（软状态）、Eventually Consistent（最终一致性）。

📌 **国网考点：** BASE 不等于完全不要一致性，而是允许采用最终一致性等模型。

### 3. 物联网网关
物联网网关连接设备侧和平台侧，常见职责包括协议转换、数据汇聚、边缘处理、设备接入与安全控制。

```text
传感器/执行器 → 物联网网关 → 网络/云平台 → 业务应用
```

⚠️ **易错提醒：** 网关不是单纯的交换机，往往还承担跨协议适配和数据处理。

### 4. 生成式 AI、预训练、微调、RAG 与 Agent

| 概念 | 核心定位 |
|---|---|
| 生成式 AI | 根据输入生成文本、图像等内容 |
| 预训练 | 在大规模数据上学习通用模式 |
| 微调 | 在特定数据或任务上进一步调整模型参数 |
| RAG | 检索外部知识后辅助模型生成 |
| Agent | 围绕目标规划、调用工具并执行行动 |

RAG 典型流程：问题 → 检索知识库 → 获取相关内容 → 交给模型 → 生成回答。

📌 **国网考点：** “回答前先检索外部知识库”优先想到 RAG。

⚠️ **易错提醒：** 微调通常改变模型参数；RAG 的核心是推理时引入外部检索信息。

### 5. 公有链、联盟链、私有链

| 类型 | 参与特点 |
|---|---|
| 公有链 | 通常开放参与 |
| 联盟链 | 多个已知组织共同参与，准入受控 |
| 私有链 | 通常由单一组织控制访问和治理 |

📌 **国网考点：** 多个已知机构、许可准入、共同维护，通常对应联盟链。

### 6. PoW、PoS、PBFT

| 共识 | 典型关键词 |
|---|---|
| PoW | 算力、工作量证明 |
| PoS | 权益证明 |
| PBFT | 已知节点、多轮消息、拜占庭容错 |

⚠️ **易错提醒：** 共识机制解决节点如何就账本状态达成一致，不等同于哈希算法或数字签名。

### 7. IPv6 基础

| 对比项 | IPv4 | IPv6 |
|---|---|---|
| 地址长度 | 32 bit | 128 bit |
| 常见书写 | 点分十进制 | 冒号分隔十六进制 |
| 广播 | 支持 | 不使用 IPv4 式广播 |
| 基本首部 | 可变 | 固定 40 字节 |

IPv6 使用扩展首部机制，基本首部不含 IPv4 式首部校验和。

📌 **国网考点：** IPv6 地址长度是 128 位。

### 8. 高可用、备份、容灾

| 概念 | 核心目标 |
|---|---|
| 高可用 HA | 尽量减少服务中断 |
| 备份 Backup | 保留数据副本以便恢复 |
| 容灾 DR | 面向较大故障或灾难保障业务恢复 |

RPO（恢复点目标）关注最多能容忍丢失多长时间的数据；RTO（恢复时间目标）关注故障后允许多长时间恢复业务。

🧠 **速记：** RPO → 丢多少数据；RTO → 停多久业务。

### 9. 工业互联网
工业互联网强调信息通信技术与工业系统融合，连接人员、机器、设备、系统和数据，支撑生产优化、设备运维和供应链协同。

常见关键词：网络、平台、数据、安全、工业应用。

📌 **国网考点：** 工业互联网不是单一通信协议，也不等于普通互联网简单搬进工厂。

## 二、国网风格练习题

### 1. Kubernetes 中常见的最小调度单元是（ ）。
A. Image  
B. Pod  
C. Service  
D. Hypervisor

**答案：B**

**解析：** Pod 是 Kubernetes 中常见的最小调度单元，可包含一个或多个紧密协作的容器。

### 2. 关于 CAP，较准确的是（ ）。
A. P 表示性能  
B. 网络分区发生时通常需要在一致性和可用性间权衡  
C. 只适用于单机系统  
D. 三项永远可同时完全保证

**答案：B**

**解析：** P 是分区容错性。网络发生分区时，一致性和可用性通常需要取舍。

### 3. 最符合物联网网关职责的是（ ）。
A. 协议转换和数据汇聚  
B. 只负责网页显示  
C. 只负责数据库索引  
D. 只负责 CPU 调度

**答案：A**

**解析：** 物联网网关常承担协议转换、数据汇聚、边缘处理和设备接入。

### 4. 大模型回答企业制度问题前先检索企业知识库，这最符合（ ）。
A. RAG  
B. RAID  
C. PBFT  
D. NFV

**答案：A**

**解析：** RAG 即检索增强生成，核心是在生成前检索外部知识。

### 5. 关于 RAG 与微调，正确的是（ ）。
A. 两者都必须修改参数  
B. 微调通常调整模型参数，RAG 主要引入外部检索信息  
C. RAG 是网络协议  
D. 微调等于数据备份

**答案：B**

**解析：** 微调通常更新参数，RAG 主要在推理阶段检索外部知识作为上下文。

### 6. 多个已知机构共同维护、节点准入受控的区块链更符合（ ）。
A. 公有链  
B. 联盟链  
C. 私有云  
D. 数据湖

**答案：B**

**解析：** 联盟链强调多机构许可参与和共同治理。

### 7. 通过计算工作量竞争记账权的典型共识机制是（ ）。
A. PoW  
B. PoS  
C. PBFT  
D. RPO

**答案：A**

**解析：** PoW 是工作量证明，典型关键词是算力和计算工作量。

### 8. IPv6 地址长度为（ ）。
A. 32 bit  
B. 48 bit  
C. 64 bit  
D. 128 bit

**答案：D**

**解析：** IPv6 地址长度为 128 位，IPv4 为 32 位。

### 9. “故障后业务必须在 30 分钟内恢复”主要描述（ ）。
A. RPO  
B. RTO  
C. PUE  
D. QoS

**答案：B**

**解析：** RTO 关注业务恢复所允许的最长时间；RPO 关注可容忍的数据丢失时间范围。

### 10. 关于工业互联网，正确的是（ ）。
A. 仅指工厂 Wi-Fi  
B. 是单一工业协议  
C. 强调信息通信技术与工业系统融合  
D. 与工业数据无关

**答案：C**

**解析：** 工业互联网综合网络、平台、数据、安全和工业应用，不是单一协议。

### 11. 【滚动复习】NB-IoT 属于（ ）。
A. 典型蜂窝 LPWAN 技术  
B. 高速有线总线  
C. 图数据库  
D. 容器编排平台

**答案：A**

**解析：** NB-IoT 是蜂窝低功耗广域网络技术，适合智能表计等场景。

### 12. 【滚动复习】Hadoop 中负责集群资源管理和作业调度的是（ ）。
A. HDFS  
B. YARN  
C. DataNode  
D. MQTT

**答案：B**

**解析：** HDFS 负责分布式存储，YARN 负责资源管理与调度。

### 13. 【滚动复习】“数据留在参与方本地，多方协同训练模型”最符合（ ）。
A. 联邦学习  
B. 数据湖  
C. 服务网格  
D. PoW

**答案：A**

**解析：** 联邦学习强调原始数据尽量不集中，通过协作完成模型训练。

### 14. 【滚动复习】PUE 的公式是（ ）。
A. IT 设备能耗 / 总能耗  
B. 数据中心总能耗 / IT 设备能耗  
C. 存储容量 / 带宽  
D. 节点数 / 用户数

**答案：B**

**解析：** PUE = 数据中心总能耗 ÷ IT 设备能耗，通常越接近 1 越理想。

### 15. 【滚动复习】SDN 的典型核心思想是（ ）。
A. 控制平面与数据平面分离并增强网络可编程性  
B. 将所有网络功能固定在专用硬件  
C. 使用二维码识别设备  
D. 在密文上完成计算

**答案：A**

**解析：** SDN 强调控制与转发分离、逻辑集中控制和可编程性；网络功能软件化更偏向 NFV。
