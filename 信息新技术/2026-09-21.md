## 一、今日知识点

### 1. 虚拟机与容器

| 对比项 | 虚拟机 VM | 容器 Container |
|---|---|---|
| 隔离层次 | 硬件虚拟化之上的完整客户操作系统 | 操作系统级隔离 |
| 内核 | 各 VM 有自己的 Guest OS 内核 | 通常共享宿主机内核 |
| 开销 | 通常较大 | 通常较小 |
| 启动 | 通常较慢 | 通常较快 |
| 典型场景 | 强隔离、多 OS | 微服务、快速部署 |

- Docker 是常见容器技术与工具生态，不是虚拟机的同义词。
- Kubernetes 主要负责容器化应用的编排、部署、伸缩与管理，不是容器本身。

📌 **国网考点：** “共享宿主机内核”优先想到容器；“完整 Guest OS”优先想到虚拟机。

⚠️ **易错提醒：** 容器轻量不等于没有隔离。

### 2. 数据仓库、数据湖与湖仓一体

| 概念 | 典型特点 | 常见用途 |
|---|---|---|
| 数据仓库 | 数据治理程度高、结构明确 | BI、报表、主题分析 |
| 数据湖 | 保存大量原始、多类型数据 | 大数据探索、日志、机器学习 |
| 湖仓一体 | 兼顾数据湖灵活性与数据仓库治理分析能力 | 统一分析平台 |

- 数据仓库常强调面向主题、集成、相对稳定和分析决策。
- 数据湖可容纳结构化、半结构化、非结构化数据。
- 湖仓一体不是简单把“湖”和“仓”放在一起，而是希望在统一数据基础上兼顾开放存储、治理和分析。

📌 **国网考点：** “大量原始、多类型数据统一沉淀”更偏数据湖；成熟 BI/报表更偏数据仓库。

### 3. MQTT 与 CoAP

| 对比项 | MQTT | CoAP |
|---|---|---|
| 典型模式 | 发布/订阅 | 类 REST 请求/响应 |
| 核心角色 | Broker、Topic、发布者、订阅者 | 客户端、服务器、资源 |
| 典型底层传输 | TCP | UDP |
| 适用特点 | 轻量消息分发、遥测 | 受限设备的轻量资源访问 |

- MQTT 中发布者向 Topic 发布消息，订阅者订阅 Topic，Broker 负责转发。
- CoAP 面向受限节点和受限网络，资源访问思想与 HTTP/REST 有相似之处，但不能把 CoAP 等同于 HTTP。

🧠 **速记：** MQTT 看“主题 + Broker + 发布订阅”；CoAP 看“受限设备 + 资源 + 类 REST”。

### 4. AI：训练、推理、预训练与微调

- **训练 Training：** 利用数据调整模型参数。
- **推理 Inference：** 使用训练好的模型处理新输入并产生预测或生成结果。
- **预训练 Pre-training：** 通常先在大规模数据上学习较通用能力。
- **微调 Fine-tuning：** 在已有模型基础上用特定领域或任务数据继续训练。

```text
大规模数据 → 预训练 → 基础模型 → 微调/适配 → 任务模型 → 推理
```

📌 **国网考点：** “上线模型处理用户输入”属于推理；“根据训练数据调整权重”属于训练。

⚠️ **易错提醒：** RAG 通过检索外部知识补充上下文，不必然修改模型参数，因此不等于微调。

### 5. Merkle Tree：哈希树

- Merkle Tree（默克尔树）是一种哈希树：叶节点对应数据或数据块摘要，上层节点由子节点哈希组合后继续计算，最终得到 **Merkle Root**。
- 某项底层数据变化后，相关路径上的哈希会变化，并可能导致根哈希改变。
- 它适合支持大量数据的完整性验证，在区块链和分布式系统中很常见。

📌 **国网考点：** 哈希侧重完整性关联；数字签名侧重身份认证、完整性与不可否认等属性；Merkle Tree 侧重组织和验证大量数据摘要。

### 6. IPv6 基础

- IPv6 地址长度为 **128 bit**；IPv4 为 32 bit。
- IPv6 地址通常用十六进制和冒号表示，并支持零压缩书写。
- IPv6 基本首部相较 IPv4 有所简化，可通过扩展首部承载部分可选功能。
- IPv6 没有 IPv4 式广播，常使用组播、任播等机制满足相应通信需求。

📌 **国网考点：** 最稳定识别点是“IPv6 = 128 位”。

⚠️ **易错提醒：** 地址空间更大不等于实际传输速率必然更高。

### 7. PUE：绿色数据中心常考指标

**PUE（Power Usage Effectiveness）**：

```text
PUE = 数据中心总能耗 / IT 设备能耗
```

- 总能耗除服务器、存储、网络等 IT 设备外，还包括制冷、供配电等消耗。
- PUE 理论下限为 1；在同等条件下，越接近 1 通常表示辅助能耗占比越低。
- 例：总功率 1500 kW、IT 设备功率 1000 kW，则 PUE = 1.5。

📌 **国网考点：** PUE 通常是“越低越好”，不是越高越好。

### 8. 可信计算与硬件可信根

- **可信计算**强调从可信根出发，对系统关键组件进行度量和验证，并逐步建立信任链。
- **硬件可信根**提供较难被普通软件层随意伪造或篡改的信任基础，可支持完整性度量、密钥保护等能力。

| 概念 | 关键词 |
|---|---|
| 可信计算 | 可信根、度量、信任链 |
| 零信任 | 不默认信任、持续验证、最小权限 |
| 传统边界防护 | 网络边界、内外区域防护 |

📌 **国网考点：** “从可信根逐级建立信任链”属于可信计算；“永不默认信任、持续验证”更典型地属于零信任。

## 二、国网风格练习题

### 1. 关于虚拟机与容器，下列说法正确的是（ ）。
A. 每个容器必须包含完整客户操作系统  
B. 容器通常共享宿主机操作系统内核  
C. Kubernetes 是硬件 Hypervisor  
D. 虚拟机不能运行不同操作系统环境

**答案：B**

**解析：** 容器典型采用操作系统级隔离并共享宿主机内核；虚拟机通常包含完整 Guest OS。Kubernetes 是容器编排平台。

### 2. 保存大量原始日志、图像及结构化业务数据，供后续多种分析任务使用，最符合（ ）。
A. 数据湖  
B. DNS  
C. Hypervisor  
D. 区块链共识层

**答案：A**

**解析：** 数据湖强调大量原始、多类型数据统一沉淀；数据仓库更偏治理后的分析数据和 BI 场景。

### 3. MQTT 最典型的通信模式是（ ）。
A. 发布/订阅  
B. 页面置换  
C. 电路交换  
D. 主从复制

**答案：A**

**解析：** MQTT 典型采用发布/订阅模式，Broker 按 Topic 在发布者和订阅者之间转发消息。

### 4. 关于 MQTT 与 CoAP，下列说法错误的是（ ）。
A. MQTT 常使用 Broker  
B. CoAP 面向受限设备和网络  
C. CoAP 具有类 REST 的资源访问思想  
D. MQTT 与 CoAP 都只能运行在 TCP 上

**答案：D**

**解析：** MQTT 经典口径通常基于 TCP，而 CoAP 经典口径通常基于 UDP；二者通信模型也不同。

### 5. 已训练好的图像分类模型接收新图片并输出类别，这一过程属于（ ）。
A. 推理  
B. 预训练  
C. 共识  
D. 数据备份

**答案：A**

**解析：** 使用训练完成的模型处理新输入属于推理；利用数据调整模型参数属于训练。

### 6. 关于 RAG 与微调，正确的是（ ）。
A. RAG 必然修改模型参数  
B. 微调完全不使用任务数据  
C. RAG 可检索外部知识补充上下文，而不必修改模型参数  
D. 二者完全相同

**答案：C**

**解析：** RAG 核心是“检索 + 生成”；微调通常会继续调整模型参数，二者不能等同。

### 7. Merkle Tree 的根节点主要由什么逐层计算得到（ ）。
A. IP 地址  
B. 数据哈希  
C. CPU 主频  
D. 无线信道号

**答案：B**

**解析：** Merkle Tree 是哈希树，底层数据摘要逐层组合计算形成上层哈希，最终得到 Merkle Root。

### 8. IPv6 地址长度为（ ）。
A. 32 bit  
B. 48 bit  
C. 64 bit  
D. 128 bit

**答案：D**

**解析：** IPv4 为 32 位，IPv6 为 128 位，这是最基础的辨识点。

### 9. 某数据中心总功率为 1200 kW，IT 设备功率为 800 kW，其 PUE 为（ ）。
A. 0.67  
B. 1.0  
C. 1.5  
D. 2.0

**答案：C**

**解析：** PUE = 1200 / 800 = 1.5。通常越接近 1，能源利用效率越高。

### 10. “从硬件可信根开始，对启动过程关键组件逐级度量并建立信任链”最符合（ ）。
A. 可信计算  
B. CDN  
C. MapReduce  
D. 网络切片

**答案：A**

**解析：** 可信根、完整性度量、信任链是可信计算的典型关键词。

### 11. 【间隔复习】Hadoop 中主要负责集群资源管理的是（ ）。
A. HDFS  
B. YARN  
C. NFC  
D. Docker

**答案：B**

**解析：** YARN 负责资源管理与调度；HDFS 负责分布式存储；MapReduce 是经典批处理计算模型。

### 12. 【间隔复习】5G 三大典型场景中强调海量设备连接的是（ ）。
A. eMBB  
B. URLLC  
C. mMTC  
D. SaaS

**答案：C**

**解析：** mMTC 强调海量机器类通信；eMBB 强调增强移动宽带；URLLC 强调超可靠低时延通信。

### 13. 【间隔复习】企业同时使用自建私有云与公有云资源，最符合（ ）。
A. 社区云  
B. 混合云  
C. 纯私有云  
D. PaaS

**答案：B**

**解析：** 混合云组合使用不同云基础设施。PaaS 是服务模型，不是部署模型。
