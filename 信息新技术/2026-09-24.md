## 一、今日知识点

### 1. Docker 与 Kubernetes：一个偏“容器”，一个偏“编排”

| 技术 | 核心定位 | 高频关键词 |
|---|---|---|
| Docker | 容器镜像构建、分发和容器运行相关技术体系 | Image、Container、轻量部署 |
| Kubernetes（K8s） | 容器化应用的自动部署、伸缩和管理平台 | 编排、调度、自愈、服务发现 |

- **镜像 Image**可理解为创建容器所依据的只读模板；**容器 Container**是镜像运行后的实例之一。
- Kubernetes 面向一组机器上的容器化工作负载，解决调度、扩缩容、故障恢复、服务暴露等问题。
- Kubernetes 并不是一种容器格式，也不是用来替代所有容器运行技术的“操作系统”。
- 容器通常共享宿主机内核，与每台虚拟机拥有独立 Guest OS 的方式不同。

📌 **国网考点：** “容器编排、自动伸缩、故障后重新调度”优先选 Kubernetes；“镜像构建与容器化封装”更偏 Docker。

⚠️ **易错提醒：** Docker ≠ Kubernetes；容器 ≠ 虚拟机。

### 2. Spark 与 Flink：大数据计算引擎的考试级辨析

| 对比项 | Spark | Flink |
|---|---|---|
| 基本定位 | 通用分布式数据处理引擎 | 分布式流处理引擎，也支持批处理 |
| 高频印象 | 内存计算、批处理，也支持流式处理 | 流优先、低延迟、持续数据流 |
| 与 Hadoop 关系 | 可与 Hadoop 生态协同，但不等于 Hadoop | 也是独立计算框架，可接入多种数据源 |

- Hadoop 生态中，**HDFS 偏分布式存储，YARN 偏资源管理，MapReduce 偏批处理计算模型**。
- Spark 通过以内存计算为代表的机制提高许多迭代式数据处理任务效率。
- Flink 强调有状态流处理，对持续到达的数据进行实时或近实时计算是其典型场景。
- 现代 Spark 也能做流式处理，因此不能简单说“Spark 只能批、Flink 只能流”。

🧠 **速记：** HDFS 存、YARN 管资源、MapReduce 算批；Spark 通用且重内存，Flink 流处理辨识度高。

### 3. 物联网网关：连接“现场设备”和“上层平台”的桥梁

物联网网关通常位于设备侧与网络/云平台之间，可承担协议转换、数据汇聚、设备接入、边缘预处理和安全接入等功能。

典型链路：

`传感器/执行器 → 物联网网关 → 网络/平台 → 业务应用`

- 不同现场设备可能使用 Zigbee、Bluetooth、工业现场协议等，网关可进行协议适配。
- 网关可以先过滤、聚合数据，再上传云端，从而减少无效流量并改善响应时延。
- **网关不等于传感器**：传感器主要感知物理量，网关更偏连接、汇聚和转换。
- **网关不等于云平台**：它更靠近现场设备，是云边端协同中的重要节点。

📌 **国网考点：** “异构协议转换、设备数据汇聚、边缘预处理”常指物联网网关。

### 4. 监督学习、无监督学习、强化学习：先看有没有标签和奖励

| 学习范式 | 训练信息 | 典型任务 |
|---|---|---|
| 监督学习 | 有输入及对应标签 | 分类、回归 |
| 无监督学习 | 通常没有人工目标标签 | 聚类、结构发现 |
| 强化学习 | 智能体与环境交互，通过奖励反馈学习策略 | 决策、控制 |

- **分类**预测离散类别，如“正常/异常”；**回归**预测连续数值，如负荷预测值。
- **聚类**根据数据相似性自动形成若干组，典型属于无监督学习。
- 强化学习的关键不是“有标签”，而是**状态—动作—奖励—策略**式交互。
- 半监督学习通常同时利用少量有标签数据和大量无标签数据。

⚠️ **易错提醒：** 聚类不是分类；奖励信号也不能简单等同于监督学习中的标签。

### 5. SDN 与 NFV：一个“网络控制软件化”，一个“网络功能虚拟化”

| 技术 | 核心思想 | 高频关键词 |
|---|---|---|
| SDN | 控制平面与数据转发平面解耦，集中/逻辑集中控制 | 控制器、可编程网络、转控分离 |
| NFV | 将传统专用网络设备上的功能以软件方式运行在通用计算平台 | 虚拟网络功能、通用硬件 |

- SDN 重点回答“**网络如何被控制和编程**”。
- NFV 重点回答“**防火墙、负载均衡等网络功能如何从专用硬件中解耦出来**”。
- 二者可以协同部署，但并非互相包含，也不是同一概念的两个名称。

📌 **国网考点：** 看到“控制器统一下发转发规则”想 SDN；看到“网络功能运行在通用服务器虚拟化环境”想 NFV。

### 6. 差分隐私：保护的是“单个样本是否参与”带来的影响

差分隐私（Differential Privacy）的核心思想是：通过对查询结果、统计过程或训练过程引入受控随机性，使攻击者难以从输出中判断某个个体的数据是否包含在数据集中。

- 它强调对**个体贡献的隐私保护**，常见手段包括加入经过设计的随机噪声。
- 差分隐私并不是“把原始数据全部加密后永远不解密”。
- 与**联邦学习**不同：联邦学习强调数据尽量留在本地、交换模型更新等信息；差分隐私强调输出对单个个体数据变化不敏感到可控程度。
- 两者可以组合使用，并非二选一。

⚠️ **易错提醒：** 差分隐私 ≠ 同态加密 ≠ 安全多方计算。它们都可服务隐私保护，但技术思路不同。

### 7. 高可用、备份、容灾：三个目标不要混

| 概念 | 主要目标 | 典型手段 |
|---|---|---|
| 高可用 HA | 尽量减少服务中断 | 冗余、故障切换、集群 |
| 备份 Backup | 保留可恢复的数据副本 | 全量/增量等备份 |
| 容灾 DR | 灾难发生后恢复业务与数据 | 异地副本、灾备中心、切换机制 |

- 高可用关注“服务尽量不断”，备份关注“数据有副本可恢复”，容灾关注“重大故障后整体恢复能力”。
- **RPO**回答“最多可接受丢失多长时间的数据”；**RTO**回答“业务最多可接受中断多久”。
- 做了备份并不自动等于实现高可用，因为恢复备份本身可能需要较长时间。

🧠 **速记：** HA 看不停，Backup 看副本，DR 看灾后恢复；RPO 看数据点，RTO 看恢复时间。

### 8. 数字孪生与 CPS：都连接虚实，但关注角度不同

- **数字孪生（Digital Twin）**：为物理对象、设备、系统或过程建立可动态映射的数字化模型，并结合实时或历史数据进行监测、分析、仿真和优化。
- **CPS（Cyber-Physical Systems，信息物理系统）**：强调计算、通信与物理过程深度融合，形成感知、计算、通信、控制的闭环。

| 概念 | 重点 |
|---|---|
| 数字孪生 | 物理对象的数字映射、状态同步、仿真分析 |
| CPS | 信息空间与物理过程融合及闭环控制 |
| 物联网 | 设备感知、连接和数据交换 |

典型智能电网场景中，可通过传感器采集设备状态，在数字空间形成设备模型，结合分析结果辅助运维；若进一步强调计算结果反向作用于物理过程，则体现更强的 CPS 闭环特征。

📌 **国网考点：** “物理设备对应动态数字模型”优先想到数字孪生；“感知—计算—控制闭环”优先想到 CPS。

## 二、国网风格练习题

### 1. 下列技术中，主要用于容器化应用自动部署、调度和伸缩的是（ ）。

A. Kubernetes  
B. HDFS  
C. MQTT  
D. PBFT

**答案：A**

**解析：** Kubernetes 是容器编排平台，典型能力包括部署、调度、扩缩容和故障恢复。HDFS 是分布式文件系统；MQTT 是轻量消息协议；PBFT 是拜占庭容错共识机制。

### 2. 关于 Docker 与 Kubernetes，下列说法正确的是（ ）。

A. Kubernetes 是一种图数据库  
B. Docker 和 Kubernetes 完全等价  
C. Docker 常用于容器镜像与容器运行，Kubernetes 侧重容器编排  
D. Kubernetes 只能运行一个容器

**答案：C**

**解析：** 二者定位不同且常配合使用。Kubernetes 面向容器化工作负载的编排管理，并不等于 Docker。

### 3. 在 Hadoop 相关技术中，主要承担分布式文件存储的是（ ）。

A. YARN  
B. HDFS  
C. Flink  
D. Kubernetes

**答案：B**

**解析：** HDFS 是 Hadoop Distributed File System，负责分布式存储；YARN 偏资源管理。此题属于近期内容的间隔复习。

### 4. 对持续到达的数据进行有状态、低延迟流式处理时，下列技术辨识度最高的是（ ）。

A. Flink  
B. NTFS  
C. Docker  
D. IPv6

**答案：A**

**解析：** Flink 以流处理为核心定位，同时也支持批处理。不能机械记成“Flink 只能流处理”。

### 5. 物联网系统中，最符合“协议转换、设备接入、数据汇聚、边缘预处理”描述的是（ ）。

A. 传感器  
B. 物联网网关  
C. 数据仓库  
D. 区块链矿工

**答案：B**

**解析：** 物联网网关位于设备与上层网络/平台之间，经常承担异构协议适配、数据汇聚和边缘处理。传感器的主要职责是感知物理量。

### 6. 使用大量已标注“正常/故障”的设备样本训练故障分类器，主要属于（ ）。

A. 无监督学习  
B. 监督学习  
C. 强化学习  
D. 共识计算

**答案：B**

**解析：** 已知样本及对应标签，并学习从输入到类别的映射，属于监督学习。分类是监督学习的典型任务。

### 7. 根据用户行为相似度，在没有预先类别标签的情况下自动划分用户群，最符合（ ）。

A. 聚类  
B. 回归  
C. 数字签名  
D. 网络切片

**答案：A**

**解析：** 聚类通常属于无监督学习，根据样本相似性发现数据中的群组结构。分类则通常依赖已有类别标签。

### 8. “将网络控制平面与数据转发平面解耦，通过控制器对网络进行可编程控制”描述的是（ ）。

A. NFV  
B. SDN  
C. SaaS  
D. RAID

**答案：B**

**解析：** SDN 的高频关键词是控制与转发解耦、控制器和可编程网络。NFV 的重点是把网络功能从专用硬件中解耦，以软件形式运行在通用平台。

### 9. 将防火墙等网络功能以软件形式部署到通用计算平台，最符合（ ）。

A. NFV  
B. SDN 的唯一含义  
C. RAG  
D. RFID

**答案：A**

**解析：** NFV 即网络功能虚拟化，重点在网络功能的软件化与通用硬件承载。SDN 与 NFV 可以协同，但概念不同。

### 10. 关于差分隐私，下列说法最恰当的是（ ）。

A. 必须把所有数据永久加密且禁止计算  
B. 通过受控随机性限制单个个体数据对输出的影响  
C. 与联邦学习完全相同  
D. 只能用于区块链

**答案：B**

**解析：** 差分隐私关注单个个体是否参与数据集对结果造成的可辨识影响，常通过受控随机噪声等机制实现。它与联邦学习、同态加密、安全多方计算的技术路线不同。

### 11. 某系统发生故障后可自动切换到冗余节点，以尽量保持服务连续，该设计首先体现（ ）。

A. 高可用  
B. 聚类  
C. 对象存储  
D. mMTC

**答案：A**

**解析：** 冗余和自动故障切换是高可用常见手段。备份主要解决数据副本与恢复问题，不能单凭“有备份”推出服务可以快速自动切换。

### 12. “为实际变电设备建立随运行数据动态更新的数字模型，用于状态监测与仿真分析”最符合（ ）。

A. 数字孪生  
B. PoW  
C. IaaS  
D. NFC

**答案：A**

**解析：** 数字孪生强调物理实体与数字模型之间的映射和数据驱动更新。CPS 更突出信息系统与物理过程的深度融合及控制闭环。

### 13. 企业问答系统先从内部知识库检索相关资料，再把检索结果交给大模型生成答案，这一模式是（ ）。

A. RAG  
B. RAID  
C. NFV  
D. PBFT

**答案：A**

**解析：** RAG 即检索增强生成，核心流程是“检索外部知识 → 作为上下文 → 生成”。这是对昨日生成式 AI 内容的间隔复习。

### 14. 关于 5G 三大典型场景，下列对应正确的是（ ）。

A. eMBB——海量低功耗设备连接  
B. URLLC——超可靠低时延通信  
C. mMTC——只用于高清视频  
D. MEC——5G 三大典型场景之一

**答案：B**

**解析：** eMBB 偏增强移动宽带，URLLC 偏超可靠低时延，mMTC 偏海量机器类通信。MEC 是多接入边缘计算，不属于这三个场景名称。
