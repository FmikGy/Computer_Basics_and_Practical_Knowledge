## 一、今日知识点

### 1. 微服务与服务网格：业务拆分 vs 通信治理

| 概念 | 核心定位 | 常见关键词 |
|---|---|---|
| 单体架构 | 多个业务功能集中部署 | 简单、耦合较集中 |
| 微服务 | 将应用拆成可独立开发、部署的较小服务 | 独立部署、服务自治、API |
| 服务网格（Service Mesh） | 为服务间通信提供基础设施层治理 | 流量管理、可观测性、安全通信 |

- 微服务解决的是**应用如何拆分和自治**；服务网格更偏向**服务之间如何可靠、安全、可观察地通信**。
- 服务网格通常不承载业务逻辑本身，而把重试、熔断、流量控制、身份认证等横切能力从业务代码中抽离。
- 云原生不等于“只要用了容器”。容器、微服务、声明式管理、自动化等都是常见云原生实践。

📌 **国网考点：** 题干出现“将通信治理能力从业务代码中抽离”时，优先想到服务网格。

⚠️ **易错提醒：** Kubernetes 是容器编排平台；Service Mesh 侧重服务通信治理，两者可以配合但不是同一概念。

### 2. 数据仓库、数据湖与湖仓一体

| 类型 | 典型特点 | 更适合 |
|---|---|---|
| 数据仓库 | 数据通常经过清洗、建模后进入，结构较规范 | BI、报表、稳定分析 |
| 数据湖 | 可保存大量原始的结构化、半结构化和非结构化数据 | 灵活分析、数据科学 |
| 湖仓一体 | 尝试结合数据湖的开放灵活与数据仓库的治理/分析能力 | 统一数据分析平台 |

- 数据仓库强调**面向分析、经过组织和治理的数据**。
- 数据湖强调以较低成本集中保存多类型、原始或近原始数据。
- “湖仓一体”不是简单把两个系统名字拼起来，而是希望在统一数据基础上兼顾开放存储、治理、事务/一致性能力和分析性能。

📌 **国网考点：** “先保存原始多类型数据，未来再按需要处理”更符合数据湖思路。

⚠️ **易错提醒：** 数据湖若缺乏元数据、质量和权限治理，可能演变成难以利用的“数据沼泽”。

### 3. MQTT 与 CoAP：物联网应用层协议辨析

| 协议 | 常见模式 | 典型特点 |
|---|---|---|
| MQTT | 发布/订阅 | 轻量，常借助 Broker（代理）转发消息 |
| CoAP | 请求/响应，风格类似轻量 Web | 面向受限设备和受限网络，常基于 UDP |

**MQTT：**
- 发布者向主题（Topic）发布消息；订阅者订阅主题；Broker 负责消息分发。
- 适合设备遥测、状态上报、消息推送等。

**CoAP：**
- 面向资源，可使用类似 GET、POST、PUT、DELETE 的方法语义。
- 适合资源受限的物联网设备。

🧠 **速记：** MQTT 看“主题 + 发布订阅 + Broker”；CoAP 看“受限设备 + 轻量请求响应”。

### 4. AI 的训练与推理：学习参数 vs 使用模型

- **训练（Training）**：利用训练数据调整模型参数，使模型学习规律，通常计算量较大。
- **推理（Inference）**：使用已经训练好的模型，对新输入产生分类、预测或生成结果。
- 模型训练完成后可以多次执行推理；推理并不等于继续修改模型参数。
- 微调（Fine-tuning）属于进一步训练的一类方式，通常基于预训练模型和特定数据进行适配。

📌 **国网考点：** “部署到终端后识别图片”主要是推理；“用标注样本更新网络权重”属于训练。

⚠️ **易错提醒：** 训练和推理都可能使用 GPU 等加速硬件，不能用“是否使用 GPU”区分二者。

### 5. Merkle Tree：区块链中的高效摘要结构

- Merkle Tree（默克尔树）是一种以**哈希**为基础的树形数据结构。
- 叶子节点通常对应数据项的哈希；上层节点由其子节点摘要进一步计算，最终形成 Merkle Root（根哈希）。
- 若底层数据发生变化，相应路径上的哈希会变化，因此可用于高效验证数据完整性和成员关系。
- 它本身不是共识算法，也不等于数字签名。

📌 **国网考点：** “用少量哈希信息证明某条交易属于某个集合/区块”常对应 Merkle Tree。

### 6. IPv6：128 位地址是最稳的识别点

| 项目 | IPv4 | IPv6 |
|---|---|---|
| 地址长度 | 32 bit | 128 bit |
| 常见文本表示 | 点分十进制 | 十六进制冒号分隔 |
| 广播 | 支持 | 不使用传统广播，更多采用组播等机制 |

- IPv6 的核心动因之一是扩大地址空间。
- IPv6 还对报头设计、自动配置、组播等方面进行了改进。
- IPv6 地址常写成多组十六进制数，连续的全 0 字段可按规则压缩表示。

📌 **国网考点：** 看到“128 位网络层地址”直接联想到 IPv6。

⚠️ **易错提醒：** IPv6 并不是“地址更多的 IPv4”这么简单，但选择题中地址长度通常是最稳定的基础考点。

### 7. 可信计算与硬件可信根

- 可信计算强调从可信根出发，对平台启动、软件状态等进行度量、验证和信任链构建。
- **硬件可信根**提供较难被普通软件篡改的信任起点。
- TPM（可信平台模块）是常见的可信计算相关硬件/模块概念，可用于密钥保护、平台度量等。
- 可信计算强调“系统状态是否符合预期、能否被验证”，与传统杀毒软件依赖恶意代码检测的思路不同。

📌 **国网考点：** “从启动阶段建立信任链”“硬件级保护密钥/度量值”是可信计算典型关键词。

### 8. PUE：绿色数据中心的经典指标

**PUE（Power Usage Effectiveness，电能使用效率）**常表示为：

```text
PUE = 数据中心总能耗 / IT 设备能耗
```

- 数据中心总能耗不仅包括服务器、存储、网络设备，还包括制冷、供配电损耗等辅助能耗。
- 在定义口径一致的前提下，PUE 越接近 1，表示非 IT 辅助能耗占比越小、能源利用效率通常越高。
- PUE 主要衡量能源使用效率，不直接等同于计算性能、可用性或碳排放总量。

⚠️ **易错提醒：** 不是“PUE 越大越节能”。

### 9. 数字孪生：物理实体与数字模型持续映射

- 数字孪生是对物理对象、过程或系统建立数字化模型，并结合实际运行数据保持映射、分析和反馈。
- 典型链路可记为：

```text
物理实体 → 传感采集 → 数据传输/平台 → 数字模型 → 分析预测 → 优化反馈
```

- 与普通静态三维模型相比，数字孪生更强调**数据驱动、状态同步、分析预测和全生命周期关联**。
- 在智能电网、设备运维、制造业中，可用于状态监测、故障预测、方案仿真等。

📌 **国网考点：** “物理设备与数字模型动态映射、利用实时数据辅助预测维护”优先选择数字孪生。

## 二、国网风格练习题

### 1. 在云原生架构中，主要用于处理服务间流量治理、可观测性和安全通信的技术是（ ）。
A. HDFS  
B. Service Mesh  
C. RAID  
D. RFID

**答案：B**

**解析：** Service Mesh（服务网格）专注服务间通信治理，可提供流量管理、可观测性和安全等横切能力。HDFS 是分布式文件系统，RAID 是磁盘组织技术，RFID 是无线识别技术。

### 2. 下列关于数据湖的描述，最符合其典型特征的是（ ）。
A. 只能保存结构化关系数据  
B. 数据必须全部预先建立固定报表模型后才能进入  
C. 可集中保存多类型原始或近原始数据  
D. 只能用于实时流处理

**答案：C**

**解析：** 数据湖强调容纳结构化、半结构化和非结构化等多类型数据，常先保存再按需求处理。A、B 将其错误等同于传统结构严格的数据平台；D 把用途限定得过窄。

### 3. MQTT 最典型的通信模式是（ ）。
A. 发布/订阅  
B. 仅电路交换  
C. 令牌环访问  
D. 磁盘镜像

**答案：A**

**解析：** MQTT 典型采用发布/订阅模式，消息通常由 Broker 根据 Topic 分发。其余选项分别属于通信交换、局域网历史访问机制或存储领域概念。

### 4. 在机器学习系统中，使用已经训练完成的模型对新样本进行预测，称为（ ）。
A. 推理  
B. 编译  
C. 共识  
D. 分片

**答案：A**

**解析：** 推理是将训练好的模型应用于新输入并得到输出。训练侧重通过数据更新参数。

### 5. 关于 Merkle Tree，下列说法正确的是（ ）。
A. 它是一种无线接入协议  
B. 它以哈希为基础，可支持高效完整性验证  
C. 它就是 PoW 共识机制  
D. 它用于替代所有数字签名

**答案：B**

**解析：** Merkle Tree 是哈希树，可通过根哈希和验证路径高效验证数据。它不是无线协议，也不是共识算法，更不能等同或替代数字签名。

### 6. IPv6 地址长度为（ ）。
A. 16 bit  
B. 32 bit  
C. 64 bit  
D. 128 bit

**答案：D**

**解析：** IPv6 地址长度为 128 bit；IPv4 为 32 bit。这是新型网络相关选择题的基础识别点。

### 7. 下列最符合可信计算思想的是（ ）。
A. 只依靠文件扩展名判断程序是否安全  
B. 从硬件可信根出发建立平台信任链  
C. 只要接入内网就默认可信  
D. 删除全部日志以减少攻击面

**答案：B**

**解析：** 可信计算强调可信根、度量和信任链。C 与零信任等现代安全理念也相冲突；A、D 均不是可信计算机制。

### 8. 某数据中心总能耗为 IT 设备能耗的 1.3 倍，则按常见定义其 PUE 为（ ）。
A. 0.3  
B. 0.7  
C. 1.3  
D. 2.3

**答案：C**

**解析：** PUE = 数据中心总能耗 / IT 设备能耗，因此为 1.3。PUE 在相同统计口径下通常越接近 1 越好。

### 9. 某电力设备在数字空间建立模型，并持续接收现场传感数据，用于预测故障和优化检修，这最符合（ ）。
A. 数字孪生  
B. 关系代数  
C. 传统静态网页  
D. 编译优化

**答案：A**

**解析：** 数字孪生强调物理实体与数字模型的持续映射，并借助运行数据进行分析、预测和反馈，非常适合设备状态监测和预测性维护场景。

### 10. 关于微服务与 Kubernetes，下列说法正确的是（ ）。
A. 微服务等同于 Kubernetes  
B. Kubernetes 主要用于容器编排，微服务是一种应用架构思想  
C. Kubernetes 是数据库管理系统  
D. 微服务要求所有服务必须运行在同一进程

**答案：B**

**解析：** 这是跨日复习题。微服务强调业务拆分与服务自治；Kubernetes 是容器编排平台。两者常结合使用但不能画等号。

### 11. Hadoop 生态中，主要负责集群资源管理和任务调度的是（ ）。
A. YARN  
B. HDFS  
C. NFC  
D. MQTT

**答案：A**

**解析：** 跨日复习：HDFS 负责分布式存储，MapReduce 是批处理计算模型，YARN 负责资源管理和任务调度。

### 12. 5G 三大典型场景中，面向海量物联网终端连接的是（ ）。
A. eMBB  
B. URLLC  
C. mMTC  
D. SaaS

**答案：C**

**解析：** 跨日复习：mMTC 强调海量机器类通信；eMBB 强调增强移动宽带；URLLC 强调超可靠低时延通信。

### 13. 关于联邦学习，下列说法最准确的是（ ）。
A. 必须把所有参与方原始数据集中到同一服务器  
B. 可在原始数据尽量留在本地的情况下协同训练模型  
C. 它是一种区块链共识机制  
D. 它与机器学习无关

**答案：B**

**解析：** 联邦学习允许多个参与方在原始数据不直接集中汇总的情况下协同训练，常交换模型更新等信息。它有助于数据协作，但并不自动解决所有隐私与安全问题。

### 14. 下列关于 RFID 与 NFC 的说法，较准确的是（ ）。
A. NFC 常用于近距离交互和非接触支付等场景  
B. RFID 只能在互联网骨干网中使用  
C. NFC 是一种分布式文件系统  
D. RFID 与无线识别无关

**答案：A**

**解析：** NFC 是近场通信技术，典型场景包括近距离交互、门禁和支付；RFID 是射频识别技术，常见于标签识别、物流和资产管理。

### 15. 下列关于 SDN 与 NFV 的描述，正确的是（ ）。
A. SDN 强调控制平面与数据平面解耦  
B. NFV 的核心是扩大 IP 地址长度  
C. SDN 是一种无线射频标签  
D. NFV 只能依赖专用硬件实现网络功能

**答案：A**

**解析：** 跨日复习：SDN 的典型思想是控制平面与数据平面分离并支持可编程控制；NFV 强调以软件方式在通用计算基础设施上实现网络功能，减少对专用硬件的依赖。
