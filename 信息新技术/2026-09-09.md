## 一、今日知识点

### 1. 微服务与服务网格：一个拆业务，一个管通信

**微服务（Microservices）**是一种应用架构思想：把大型应用拆成多个围绕业务能力构建、可相对独立开发和部署的小服务。

| 概念 | 核心关注 | 典型关键词 |
|---|---|---|
| 单体应用 | 多个功能集中部署 | 一个整体、耦合较集中 |
| 微服务 | 业务拆分与独立演进 | 小服务、独立部署、API |
| 服务网格 Service Mesh | 服务间通信治理 | 流量管理、可观测、安全通信 |

服务网格通常把服务发现后的通信治理、流量控制、可观测性和安全策略等能力从业务代码中抽离出来，由基础设施层统一处理。

📌 **国网考点：** “将复杂应用拆为可独立部署的小服务”选微服务；“统一治理服务间通信”更接近服务网格。

⚠️ **易错提醒：** 微服务不等于容器，容器只是常见承载方式；服务网格也不是把微服务再次拆分。

---

### 2. NoSQL 四类常见模型：别把“非关系型”理解成“没有结构”

NoSQL 常用于海量、分布式、灵活数据模型等场景，考试常按数据组织方式辨析。

| 类型 | 数据组织直觉 | 典型适用特征 |
|---|---|---|
| 键值型 | Key → Value | 高速按键访问、缓存 |
| 文档型 | JSON/类文档结构 | 字段较灵活、半结构化数据 |
| 列族型 | 按列族组织 | 大规模稀疏数据、分布式存储 |
| 图数据库 | 节点 + 边 | 社交关系、知识关系、路径关联 |

📌 **国网考点：** 题干若强调“关系之间的连接与路径查询”，图数据库最有辨识度。

⚠️ **易错提醒：** NoSQL 通常解释为“Not Only SQL”，并不意味着完全不能查询，也不意味着数据毫无结构。

### 3. RFID、二维码：都能标识对象，但读取机制不同

| 技术 | 主要载体/机制 | 是否通常要求光学可见 | 典型场景 |
|---|---|---|---|
| RFID | 标签 + 无线射频识别 | 否 | 物流、仓储、资产识别 |
| 二维码 | 图形编码 + 光学扫描 | 是 | 支付、票证、商品信息 |
| NFC | 极近距离无线通信 | 否 | 门禁、支付、碰一碰 |

RFID 系统一般包括**电子标签、读写器**等组成部分，可在一定条件下实现非接触识别；二维码依赖摄像头或扫描器获取图形信息。

📌 **国网考点：** “无需可视对准、利用射频识别标签”优先选 RFID。

🧠 **速记：** 二维码“看图读”，RFID“射频读”，NFC“贴近交互”。

### 4. AI Agent：大模型不只是回答，还能围绕目标执行步骤

**AI Agent（智能体）**通常指能够围绕目标感知上下文、规划或选择行动，并调用工具或外部系统完成任务的智能系统形态。

可用简化链路理解：

```text
目标/输入 → 理解与规划 → 选择工具或行动 → 获取结果 → 根据结果继续处理
```

- **大语言模型（LLM）**可作为 Agent 的推理与语言能力核心之一，但二者不是同义词。
- **RAG**重点是“检索外部知识再辅助生成”；**Agent**更强调围绕目标进行行动、工具调用和多步骤协作。
- **提示工程**主要优化输入提示，本身不等于构建 Agent。

📌 **国网考点：** 出现“自主选择工具、执行多步骤任务”时，更符合 Agent 的典型定位。

⚠️ **易错提醒：** Agent 并不意味着完全无人监督，也不能保证每次规划或工具调用都正确。

### 5. 区块链中的哈希与数字签名：完整性与身份鉴别不能混

| 技术 | 主要作用 | 是否需要私钥完成核心操作 |
|---|---|---|
| 哈希 | 生成固定长度摘要、辅助完整性校验 | 否 |
| 数字签名 | 身份鉴别、完整性、不可否认性支持 | 是，签名者使用私钥签名 |

区块链通过哈希把区块内容与前序信息关联，使历史数据被修改后容易被发现；数字签名则用于证明交易等数据由相应私钥控制者签发，并可验证内容是否被改动。

📌 **国网考点：** “摘要/指纹”对应哈希；“私钥签名、公钥验证”对应数字签名。

⚠️ **易错提醒：** 哈希不是加密，通常不能通过摘要反推出原文；数字签名的主要目的也不是保密数据内容。

### 6. 5G 网络切片与 MEC：一个“逻辑分网”，一个“计算下沉”

**网络切片（Network Slicing）**是在共享物理基础设施上构建多个逻辑上相对独立的网络，以针对不同业务提供差异化网络能力。

**MEC（多接入边缘计算）**把计算、存储等能力部署到更靠近用户或数据源的位置，以降低时延、减少核心网络回传压力。

| 概念 | 核心动作 | 典型目标 |
|---|---|---|
| 网络切片 | 一套基础设施提供多种逻辑网络 | 差异化网络能力 |
| MEC | 计算能力靠近接入侧/用户侧 | 低时延、本地处理 |

📌 **国网考点：** “同一物理网络为不同业务提供逻辑隔离网络”选网络切片；“业务处理下沉到接入边缘”选 MEC。

### 7. 可信计算与硬件可信根：从“系统是否可信”出发

**可信计算**关注计算平台能否建立、度量和验证可信状态。其思想不是只在网络边界挡攻击，而是从平台自身建立信任基础。

- **硬件可信根**：以受保护的硬件能力作为信任起点。
- **度量**：对启动组件、软件状态等形成可验证的度量值。
- **信任链**：从可信起点逐级验证后续组件。

📌 **国网考点：** “从硬件信任根开始建立信任链、度量启动组件”属于可信计算典型描述。

⚠️ **易错提醒：** 可信计算不等于传统杀毒软件；“可信”也不代表系统绝对不会出现漏洞。

### 8. 数据仓库、数据湖、湖仓一体：结构化分析与多类型数据管理

| 概念 | 典型特点 | 关键词 |
|---|---|---|
| 数据仓库 | 面向分析，通常强调治理后的结构化数据 | BI、主题分析、结构明确 |
| 数据湖 | 可保存大量原始、多类型数据 | 原始数据、结构灵活 |
| 湖仓一体 | 融合数据湖开放灵活与数据仓库管理分析能力 | 统一、融合 |

数据湖适合先汇聚多种原始数据再按需处理；传统数据仓库更强调经过整理、建模后的分析数据。湖仓一体试图减少湖与仓之间割裂，并非简单把二者名字拼在一起。

📌 **国网考点：** “大量原始的结构化、半结构化、非结构化数据统一存放”更偏向数据湖。

---

### 9. 智慧城市与智能电网：新技术最终要落到信息系统场景

智慧城市和智能电网通常不是某一种单独技术，而是多种信息技术的综合应用。

```text
感知：传感器、智能终端、RFID
连接：有线/无线网络、5G、物联网
计算：云计算、边缘计算
数据：大数据平台、数据湖
智能：AI 分析与辅助决策
安全：身份、访问控制、可信与隐私保护
```

在智能电网场景中，边缘节点可就近处理设备数据，云平台适合全局资源与数据分析；二者通常协同而非互相取代。

📌 **国网考点：** 题目常考“技术—场景”的合理匹配，而不是要求掌握具体行业算法。

## 二、国网风格练习题

### 1. 下列最能体现微服务架构特点的是（ ）。

A. 所有业务功能必须编译成一个不可拆分程序  
B. 按业务能力拆分为可相对独立部署的服务  
C. 所有数据必须存入同一个文件  
D. 用物理服务器替代虚拟机

**答案：B**

**解析：** 微服务强调围绕业务能力拆分，并支持服务相对独立开发、部署和演进。容器或虚拟机只是可能的承载方式，不是微服务定义本身。

### 2. 在 NoSQL 类型中，最适合突出“节点之间复杂关系和路径查询”的是（ ）。

A. 键值数据库  
B. 图数据库  
C. 文件系统  
D. 块存储

**答案：B**

**解析：** 图数据库以节点和边表达实体及关系，适合社交关系、知识图谱等关联查询。键值型主要突出按 Key 快速访问。

### 3. 某仓库希望无需摄像头对准标签，通过无线方式自动识别货物，最符合该需求的是（ ）。

A. RFID  
B. 二维码  
C. JPEG  
D. HDMI

**答案：A**

**解析：** RFID 利用射频与标签交互，可进行非接触识别；二维码通常需要光学设备看到并扫描图形。

### 4. 下列对 AI Agent 的描述最恰当的是（ ）。

A. 只能生成固定长度文本  
B. 只能用于训练神经网络  
C. 可围绕目标规划并调用工具执行多步骤任务  
D. 等同于所有大语言模型

**答案：C**

**解析：** Agent 强调目标驱动、规划/行动和工具调用。LLM 可以是 Agent 的重要组件，但 LLM 与 Agent 不是同义概念。

### 5. 在典型数字签名过程中，签名者用于生成签名的是（ ）。

A. 自己的私钥  
B. 自己的公钥  
C. 对方的公钥  
D. 对方的私钥

**答案：A**

**解析：** 典型公钥密码体系中，签名者使用自己的私钥签名，验证者使用对应公钥验证。数字签名重点是身份鉴别、完整性和不可否认性支持，而非内容保密。

### 6. “在共享物理基础设施上为不同业务构造逻辑上相对独立的网络”描述的是（ ）。

A. 网络切片  
B. 数据湖  
C. MapReduce  
D. RFID

**答案：A**

**解析：** 网络切片通过共享底层设施提供面向不同业务需求的逻辑网络。MEC 则强调把计算能力部署到网络边缘，两者不要混淆。

### 7. 将业务计算部署到更靠近接入侧的位置，以降低交互时延，最符合（ ）。

A. MEC  
B. SaaS  
C. PBFT  
D. HDFS

**答案：A**

**解析：** MEC 是边缘计算的重要形态，核心是计算和存储能力靠近用户或数据源。网络切片关注逻辑网络能力，不等同于计算下沉。

### 8. 下列最符合可信计算思想的是（ ）。

A. 仅依赖外部防火墙即可证明主机内部可信  
B. 从硬件可信根出发建立可度量、可验证的信任链  
C. 删除所有日志以减少风险  
D. 将全部业务改成离线运行

**答案：B**

**解析：** 可信计算强调可信根、度量和信任链。防火墙属于边界与网络安全手段，不能单独证明平台内部状态可信。

### 9. 某平台希望集中保存大量原始的结构化、半结构化和非结构化数据，再按需处理分析，最接近（ ）。

A. 数据湖  
B. CPU Cache  
C. 网络切片  
D. 数字签名

**答案：A**

**解析：** 数据湖强调容纳大量原始、多类型数据。传统数据仓库通常更强调经过治理、建模后的分析数据。

### 10. 关于服务网格，下列说法正确的是（ ）。

A. 主要用于把硬盘划分为多个分区  
B. 主要解决服务间通信治理等基础设施问题  
C. 是一种 NoSQL 数据模型  
D. 是 5G 的三大场景之一

**答案：B**

**解析：** Service Mesh 聚焦微服务间通信治理，例如流量管理、可观测性和安全策略等。它与存储分区、NoSQL、5G 场景无关。

### 11. 【间隔复习】Hadoop 生态中主要负责集群资源管理与作业调度的是（ ）。

A. HDFS  
B. YARN  
C. RFID  
D. Docker

**答案：B**

**解析：** YARN 负责资源管理和调度；HDFS 负责分布式存储；MapReduce 是经典分布式批处理计算模型。

### 12. 【间隔复习】在 5G 三大典型场景中，大规模机器类通信通常对应（ ）。

A. eMBB  
B. URLLC  
C. mMTC  
D. WLAN

**答案：C**

**解析：** mMTC 强调海量机器类终端连接；eMBB 偏增强移动宽带；URLLC 偏超可靠低时延通信。

### 13. 【间隔复习】访问量突然增加，云平台自动增加计算实例，最直接体现的是（ ）。

A. 弹性伸缩  
B. 数字签名  
C. 数据湖  
D. 区块链共识

**答案：A**

**解析：** 弹性伸缩根据负载动态增减资源。高可用强调减少故障导致的中断，容灾强调灾难后的业务恢复。

### 14. 【间隔复习】关于 RAG 与提示工程，下列说法正确的是（ ）。

A. RAG 的核心是检索外部信息辅助生成  
B. 提示工程必然修改模型权重  
C. RAG 等同于重新训练基础模型  
D. 提示工程只能处理图像

**答案：A**

**解析：** RAG 是“检索增强生成”，通过检索外部知识为生成提供上下文。提示工程通常优化输入指令和上下文，不要求修改模型参数。

### 15. 【间隔复习】关于零信任安全理念，最典型的表述是（ ）。

A. 内网用户默认永久可信  
B. 只要通过一次认证以后无需再验证  
C. 不因网络位置天然信任，持续基于身份与上下文验证授权  
D. 完全取消身份认证

**答案：C**

**解析：** 零信任强调“不默认信任、持续验证、最小权限”等思想，不把“已经进入内网”视为永久可信依据。

## 三、今日速记

| 看到关键词 | 优先联想 |
|---|---|
| 业务拆成可独立部署的小服务 | 微服务 |
| 服务间流量、安全、可观测治理 | Service Mesh |
| Key → Value | 键值 NoSQL |
| 节点 + 边、关系路径 | 图数据库 |
| 射频、电子标签、非接触识别 | RFID |
| 图形编码、光学扫描 | 二维码 |
| 目标 → 规划 → 工具调用 → 行动 | AI Agent |
| 摘要、数据指纹 | 哈希 |
| 私钥签名、公钥验证 | 数字签名 |
| 共享基础设施上的逻辑网络 | 5G 网络切片 |
| 计算下沉、靠近用户、低时延 | MEC |
| 可信根 → 度量 → 信任链 | 可信计算 |
| 原始、多类型数据统一存放 | 数据湖 |
| 融合湖的灵活与仓的治理分析 | 湖仓一体 |

🧠 **四组易混速记：**

- **微服务 vs 服务网格**：前者“拆业务”，后者“管服务通信”。
- **网络切片 vs MEC**：前者“逻辑分网”，后者“计算下沉”。
- **哈希 vs 数字签名**：前者“做摘要”，后者“私钥签、身份验”。
- **数据仓库 vs 数据湖**：仓偏“治理后分析”，湖偏“原始多类型汇聚”。

📌 **滚动复习钩子：** HDFS=存，MapReduce=经典批处理计算，YARN=资源管理；eMBB=增强宽带，URLLC=超可靠低时延，mMTC=海量机器通信；弹性=随负载增减资源；零信任=不因位置天然信任、持续验证。
