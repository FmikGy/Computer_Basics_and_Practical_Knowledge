## 一、今日知识点

### 1. 虚拟机、容器、Docker 与 Kubernetes：四个名词不要混

| 概念 | 核心定位 | 选择题关键词 |
|---|---|---|
| 虚拟机 | 虚拟出完整计算机环境，通常有独立客户操作系统 | Hypervisor、Guest OS |
| 容器 | 操作系统级隔离，通常共享宿主机内核 | 轻量、启动快、镜像 |
| Docker | 常见容器构建、镜像与运行工具/平台 | Image、Container |
| Kubernetes（K8s） | 容器编排平台 | 部署、调度、伸缩、服务发现、自愈 |

- 容器一般比完整虚拟机轻量，但二者都可用于隔离工作负载。
- Docker 重点解决“容器怎么构建和运行”；Kubernetes 重点解决“大量容器化应用如何编排和管理”。
- Kubernetes 并不是一种新的虚拟机，也不是操作系统。

📌 **国网考点：** 题干出现“自动调度容器、故障后重新拉起、弹性副本”时，优先想到 Kubernetes。

⚠️ **易错提醒：** “容器没有操作系统”是过度简化。容器可包含用户空间文件和依赖，但通常共享宿主机内核。

### 2. MapReduce 与 YARN：一个偏计算模型，一个偏资源管理

Hadoop 生态中三个高频名词可以这样记：

```text
HDFS：数据放哪里 → 分布式存储
MapReduce：数据怎么算 → 批处理计算模型
YARN：资源怎么分 → 集群资源管理与任务调度
```

**MapReduce**典型思想：
- Map：把输入拆分并进行并行处理，产生中间结果；
- Reduce：对中间结果进行汇总、归并等处理。

**YARN**负责管理集群计算资源，并为不同计算任务分配资源。它使 Hadoop 集群不必只服务于传统 MapReduce 作业。

📌 **国网考点：** NameNode/DataNode 属于 HDFS；Map/Reduce 是计算阶段；YARN 不负责把用户文件作为 HDFS 数据块长期保存。

### 3. RFID 与 NFC：都是无线识别，但范围和典型场景不同

| 技术 | 基本定位 | 典型特点/场景 |
|---|---|---|
| RFID | 射频识别技术总称 | 标签识别、物流、门禁、资产管理 |
| NFC | 近场通信技术 | 极近距离交互、手机支付、门禁、设备配对 |

- RFID 系统常见组成包括**标签、读写器和后台系统**。
- NFC 强调近距离双向通信，可用于支付、身份凭证和快速配对。
- NFC 与 RFID 有技术关联，但不能把所有 RFID 都称为 NFC。

⚠️ **易错提醒：** 二维码主要依赖光学扫描；RFID/NFC 使用无线射频通信，识别机制不同。

### 4. 过拟合、欠拟合与泛化：看训练集和新数据表现

| 情况 | 典型表现 | 常见理解 |
|---|---|---|
| 欠拟合 | 训练集表现也不好 | 模型没有学到足够规律 |
| 过拟合 | 训练集很好，新数据明显变差 | 过度记住训练样本细节 |
| 泛化良好 | 对未见数据仍有较好表现 | 学到较稳定的规律 |

缓解过拟合的常见思路包括增加有效训练数据、适当正则化、控制模型复杂度、使用验证集进行模型选择等。

📌 **国网考点：** “训练准确率很高、测试准确率明显较低”是过拟合的典型信号。

⚠️ 不要把“训练时间长”直接等同于过拟合；判断关键是训练数据与未见数据上的表现差异。

### 5. 哈希、数字签名与区块链链式结构

| 技术 | 主要作用 | 能否由摘要还原原文 |
|---|---|---|
| 哈希函数 | 生成固定长度摘要、检测数据变化 | 正常设计目标下不可逆 |
| 数字签名 | 身份认证、完整性验证、不可否认性支撑 | 不是用来还原原文 |

区块链中，区块通常通过对前序区块相关信息的哈希引用形成链式关联。若历史数据发生变化，相关哈希也会变化，从而使篡改容易被发现，并需要破坏后续一致性才能掩盖。

数字签名的一般考试口径：**私钥签名，公钥验证**。

⚠️ **易错提醒：** 哈希不是加密；数字签名的主要目的也不是“把消息内容保密”。需要保密通常还要使用加密机制。

### 6. 4G 与 5G：考试重点不是简单的“速度更快”

5G 相比 4G 的能力演进不仅包括更高数据速率，还面向更低时延、更大规模设备连接和更灵活的网络能力。

5G 三大典型应用场景复习：

| 场景 | 含义 | 关键词 |
|---|---|---|
| eMBB | 增强移动宽带 | 高速率、大带宽 |
| URLLC | 超可靠低时延通信 | 低时延、高可靠 |
| mMTC | 海量机器类通信 | 大连接、物联网 |

**网络切片**可在共享物理基础设施上构建面向不同业务需求的逻辑网络；**MEC**把计算能力部署到靠近用户或数据源的位置以降低时延和回传压力。

📌 **国网考点：** 5G ≠ 只有 eMBB；工业控制类题目常与 URLLC 联系，海量传感器常与 mMTC 联系。

### 7. 联邦学习：数据尽量不集中，交换模型相关信息

联邦学习是一种分布式机器学习思路：多个参与方在本地数据上训练，通过交换模型更新或相关信息进行协同建模，**原始数据原则上不必集中汇聚到同一位置**。

典型流程可简化为：

```text
下发模型 → 各方本地训练 → 上传模型更新 → 聚合 → 得到新模型
```

它适合数据难以直接汇聚、存在隐私或合规要求的跨机构协同场景。

⚠️ **易错提醒：** 联邦学习不等于“天然绝对安全”。模型更新仍可能带来隐私风险，实际系统可结合安全聚合、差分隐私等技术。

🧠 **辨析：** 联邦学习解决“数据不集中也能协同训练”；差分隐私侧重通过受控随机扰动限制单条记录对输出的影响；同态加密强调对密文进行特定计算。

### 8. RAID、高可用与备份：冗余不能替代备份

RAID 通过多个磁盘组合提升性能和/或容错能力。考试常见基础口径：

| RAID | 核心特点 |
|---|---|
| RAID 0 | 条带化，性能高，但无冗余容错 |
| RAID 1 | 镜像，数据冗余，容量利用率较低 |
| RAID 5 | 条带化 + 分布式奇偶校验，可容忍单盘故障（典型口径） |

**高可用（HA）**强调减少服务中断，通过冗余、故障检测、切换等手段维持业务连续性。

⚠️ RAID 不是备份。误删除、恶意加密或逻辑损坏可能同步影响冗余副本；备份强调保留可恢复的数据副本。

📌 若题目问容灾指标：RPO 偏“最多可容忍丢多少时间范围的数据”，RTO 偏“业务最多多久恢复”。

### 9. 智慧电网中的云、边、物联与数字孪生

智慧电网常把多类新技术组合使用，而不是由单一技术完成全部任务：

- **物联网/传感器**：采集设备状态、环境与运行数据；
- **边缘计算**：在站端、设备附近进行快速处理和响应；
- **云/数据平台**：承担跨区域汇聚、集中分析和统一管理；
- **AI**：用于状态识别、预测、辅助决策等；
- **数字孪生**：建立物理对象或系统的数字化映射，并结合实时/历史数据支持监测、分析和仿真。

⚠️ **易错提醒：** 数字孪生不只是静态三维模型；其核心价值通常还包括与物理对象状态关联、数据驱动更新和分析应用。

## 二、国网风格练习题

### 1. 下列最符合 Kubernetes 定位的是（ ）。
A. 关系数据库管理系统  
B. 容器编排与管理平台  
C. 分布式文件系统  
D. 区块链共识协议

**答案：B**

**解析：** Kubernetes 主要负责容器化应用的部署、调度、伸缩和故障恢复等编排工作。HDFS 才是典型分布式文件系统。

### 2. 与完整虚拟机相比，容器通常更轻量的重要原因是（ ）。
A. 容器不需要任何操作系统相关组件  
B. 容器通常共享宿主机操作系统内核  
C. 容器只能运行一个进程  
D. 容器不需要 CPU

**答案：B**

**解析：** 容器通常共享宿主机内核，不必为每个实例运行完整客户操作系统，因此启动和资源开销通常更小。A、C、D 都是绝对化错误表述。

### 3. Hadoop 生态中，主要负责集群资源管理与任务调度的是（ ）。
A. HDFS  
B. YARN  
C. DataNode  
D. Map

**答案：B**

**解析：** YARN 负责资源管理和任务调度；HDFS 负责分布式存储；DataNode 是 HDFS 的数据块存储节点；Map 是 MapReduce 的处理阶段。

### 4. MapReduce 中，主要用于对中间结果进行汇总、归并处理的阶段是（ ）。
A. Map  
B. Reduce  
C. NameNode  
D. YARN

**答案：B**

**解析：** Map 负责映射和并行产生中间结果，Reduce 负责对中间结果进行归并、汇总等处理。NameNode 和 YARN 都不是 MapReduce 的这两个计算阶段。

### 5. 下列关于 NFC 与 RFID 的说法正确的是（ ）。
A. NFC 与所有 RFID 完全等价  
B. RFID 必须通过摄像头读取  
C. NFC 典型特点之一是近距离交互  
D. 二者都只能用于支付

**答案：C**

**解析：** NFC 强调近场通信。RFID 是更广义的射频识别技术，常用于标签和资产识别；二维码才典型依赖光学扫描。二者应用也远不止支付。

### 6. 某模型在训练集上准确率很高，但在未见测试数据上明显下降，最可能出现（ ）。
A. 过拟合  
B. 欠拟合  
C. 数据压缩  
D. 共识失败

**答案：A**

**解析：** 训练表现很好而泛化明显较差是过拟合的典型表现。欠拟合通常连训练集都难以取得良好表现。

### 7. 关于区块链中的数字签名，正确的是（ ）。
A. 通常使用私钥签名、公钥验证  
B. 主要用于把明文压缩成固定长度  
C. 能保证链外数据一定真实  
D. 与身份认证和完整性无关

**答案：A**

**解析：** 数字签名常采用私钥签名、公钥验证，可支持身份认证和完整性验证。生成固定长度摘要是哈希函数的典型作用，数字签名也不能保证链外输入天然真实。

### 8. 大规模低功耗传感器接入最符合 5G 哪一典型场景（ ）。
A. eMBB  
B. URLLC  
C. mMTC  
D. SaaS

**答案：C**

**解析：** mMTC 强调海量机器类通信和大规模物联网连接；eMBB 偏增强宽带，URLLC 偏超可靠低时延。

### 9. 关于联邦学习，最准确的是（ ）。
A. 必须先把所有原始数据汇总到中心服务器  
B. 可让参与方保留本地数据并协同训练模型  
C. 等同于同态加密  
D. 可以自动消除全部隐私风险

**答案：B**

**解析：** 联邦学习的核心之一是原始数据尽量留在本地，通过模型更新等信息协同训练。它不等同于同态加密，也不能自动消除所有隐私风险。

### 10. 下列 RAID 级别中，典型情况下没有数据冗余的是（ ）。
A. RAID 0  
B. RAID 1  
C. RAID 5  
D. 镜像存储

**答案：A**

**解析：** RAID 0 采用条带化提高并行性能，但不提供冗余；RAID 1 采用镜像，RAID 5 使用分布式奇偶校验。

### 11. 关于 RAID 与备份的关系，正确的是（ ）。
A. 配置 RAID 后永远无需备份  
B. RAID 只用于网络切片  
C. RAID 的磁盘冗余不能替代独立备份  
D. RAID 0 能容忍任意单盘故障

**答案：C**

**解析：** RAID 可提高可用性或性能，但不能防止所有逻辑删除、恶意破坏等风险，因此不能替代备份。RAID 0 无冗余，任一成员盘故障都可能导致阵列数据不可用。

### 12. 【间隔复习】在 HDFS 中，主要保存实际数据块的是（ ）。
A. NameNode  
B. DataNode  
C. YARN  
D. Hypervisor

**答案：B**

**解析：** DataNode 保存实际数据块；NameNode 主要管理文件系统命名空间和块映射等元数据。这是 HDFS 高频职责辨析。

### 13. 【间隔复习】关于 SDN 与 NFV，正确的是（ ）。
A. SDN 强调控制平面与数据平面分离，NFV 强调网络功能软件化  
B. 二者都是无线射频识别技术  
C. NFV 就是 IPv6  
D. SDN 只能用于区块链

**答案：A**

**解析：** SDN 的经典核心是控制与转发解耦、集中可编程控制；NFV 强调将传统专用网络设备中的功能以软件方式运行在通用计算基础设施上。

### 14. 【间隔复习】在 CAP 讨论中，网络分区发生时常需要重点权衡的是（ ）。
A. 一致性与可用性  
B. CPU 与 GPU  
C. SaaS 与 PaaS  
D. RFID 与 NFC

**答案：A**

**解析：** 当网络分区必须被容忍时，CAP 的典型选择题口径是讨论一致性 C 与可用性 A 的权衡。不能简单理解为任何时候都固定“只能三选二”。

### 15. 【间隔复习】某系统希望用户直接使用在线办公软件而无需维护操作系统和应用运行环境，最符合（ ）。
A. IaaS  
B. PaaS  
C. SaaS  
D. SAN

**答案：C**

**解析：** SaaS 直接向用户提供可使用的软件服务；IaaS 提供基础资源，PaaS 提供开发运行平台，SAN 是块级存储网络概念。
