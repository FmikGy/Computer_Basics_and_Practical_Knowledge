# 信息新技术

本目录用于整理国家电网计算机类考试中“信息新技术”相关知识点与每日练习。

## 覆盖范围

长期轮换覆盖但不限于：

- 云计算：IaaS / PaaS / SaaS、虚拟化、容器、云原生、弹性、资源池化、边缘云等
- 大数据：5V 特征、Hadoop、HDFS、MapReduce、YARN、Spark、Flink、数据湖/湖仓等基础概念
- 物联网：感知层 / 网络层 / 应用层、RFID、传感器、NB-IoT、LoRa、Zigbee、MQTT 等
- 人工智能：机器学习、深度学习、神经网络、监督/无监督/强化学习、生成式 AI、大模型基础概念
- 区块链：区块、哈希、Merkle Tree、共识机制、智能合约、联盟链/公有链/私有链
- 移动互联网与新型网络：5G、IPv6、SDN、NFV、网络切片、MEC/边缘计算等
- 数据中心与绿色计算：IDC、PUE、服务器虚拟化、存储虚拟化、容灾、高可用等
- 信息安全新技术：零信任、可信计算、隐私计算、联邦学习等基础概念
- 其他国网考纲和题库中出现的信息技术新概念

## 每日文件

每天生成一个 `YYYY-MM-DD.md` 文件，内容包含：

1. 今日知识点：强调概念、分类、典型技术、易混淆点和国网常见考法。
2. 国网风格练习题：每题答案和解析紧跟题目。
3. 今日速记：压缩为考前可快速扫描的对应关系和口诀。

目标不是追求某一领域过深，而是长期扩大“信息新技术”考点覆盖面，形成适合选择题应试的知识地图。
