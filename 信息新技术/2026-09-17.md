## 一、今日知识点

### 1. 云计算基本特征：按需、资源池、弹性、计量

| 特征 | 选择题关键词 | 易混点 |
|---|---|---|
| 按需自助服务 | 用户按需要获取计算资源 | 不等于必须人工审批 |
| 广泛网络访问 | 通过网络使用服务 | 云资源不要求与用户同机 |
| 资源池化 | 多租户共享资源池、动态分配 | 不等于每用户固定独占物理机 |
| 快速弹性 | 资源可快速扩展或收缩 | 弹性强调随负载变化 |
| 可计量服务 | 使用量可监测、计量 | 常与按使用量计费联系 |

- **弹性**关注“资源随需求伸缩”；**可扩展性**更泛化，表示系统提升处理能力的能力。
- 云计算不是简单的“把服务器搬到远程”，关键还包括资源抽象、池化、自动化服务等。

📌 **国网考点：** 业务高峰自动增加实例、低谷自动释放实例，首先对应**弹性伸缩**。

### 2. 高可用、备份、容灾：目标不同

| 概念 | 核心目标 | 典型手段 |
|---|---|---|
| 高可用（HA） | 尽量减少服务中断 | 冗余、集群、故障切换 |
| 备份 | 保留数据副本以便恢复 | 全量/增量等备份 |
| 容灾（DR） | 灾难发生后维持或恢复业务 | 异地灾备、复制、切换 |

- 有备份不代表业务能立即切换，因此**备份 ≠ 高可用 ≠ 容灾**。
- 高可用更强调服务连续性；容灾面向机房级、区域级等重大故障时的恢复能力。

⚠️ **易错提醒：** RAID 提供一定磁盘冗余，但不能替代独立备份，更不能自动等同完整容灾体系。

### 3. NoSQL 四类：按数据模型识别

| 类型 | 数据组织印象 | 典型适用方向 |
|---|---|---|
| 键值型 | Key → Value | 缓存、会话、快速查找 |
| 文档型 | JSON/类似文档结构 | 内容、灵活模式数据 |
| 列族型 | 按列族组织 | 大规模稀疏数据、分布式场景 |
| 图数据库 | 节点 + 边 + 属性 | 社交关系、知识图谱、路径关系 |

- NoSQL 常强调灵活的数据模型和横向扩展能力，但它不是“完全不能查询”或“完全没有一致性”。
- 关系型数据库仍适合大量强事务和结构化关系场景，两者不是简单替代关系。

🧠 **速记：** 键值找值，文档装对象，列族做海量，图数据库找关系。

### 4. CAP 与 BASE：分布式系统的考试层次

- **C（Consistency）一致性：** 这里通常指分布式副本对外呈现一致的数据视图。
- **A（Availability）可用性：** 每个非故障请求能够获得响应。
- **P（Partition tolerance）分区容错性：** 网络分区出现时系统仍能继续按设计工作。
- CAP 的经典结论是：**发生网络分区时，分布式系统需要在 C 与 A 之间作取舍**，不是日常任何时候都只能“三选二”。

**BASE**常用于描述偏向高可用的分布式系统思想：Basically Available（基本可用）、Soft state（软状态）、Eventually consistent（最终一致性）。

📌 **国网考点：** “允许短时间数据不一致，但最终达到一致”对应**最终一致性**。

### 5. 物联网网关：连接现场与上层平台

物联网网关通常位于终端设备与上层网络/平台之间，常见作用包括：

- **协议转换：** 连接使用不同通信协议的设备与平台；
- **数据汇聚：** 汇总多个传感器/终端数据；
- **边缘处理：** 过滤、预处理或本地规则判断；
- **设备接入与管理：** 协助管理现场终端连接。

典型链路可记为：**传感器/执行器 → 网关/边缘节点 → 网络/平台 → 应用**。

⚠️ **易错提醒：** 网关不只是“放大无线信号”的设备，其关键价值之一是跨协议、跨网络连接与数据汇聚。

### 6. 监督、无监督、半监督、强化学习

| 学习方式 | 训练信息 | 典型任务/关键词 |
|---|---|---|
| 监督学习 | 有标签样本 | 分类、回归 |
| 无监督学习 | 无标签数据 | 聚类、结构发现 |
| 半监督学习 | 少量有标签 + 大量无标签 | 标签成本高的场景 |
| 强化学习 | 与环境交互，通过奖励信号学习策略 | 状态、动作、奖励 |

- **分类**预测离散类别，**回归**预测连续数值，二者通常属于监督学习任务。
- 聚类根据数据自身相似性形成群组，典型属于无监督学习。
- 强化学习不是教师直接给出每一步的标准答案，而是通过奖励反馈学习长期策略。

📌 **国网考点：** “智能体试错，根据奖励改进行为策略”优先选强化学习。

### 7. PoW、PoS、PBFT：三种典型共识不要混

| 机制 | 核心依据/方式 | 典型印象 |
|---|---|---|
| PoW | 计算工作量竞争 | 计算资源消耗较大 |
| PoS | 权益等因素参与验证/选择 | 避免 PoW 式大量算力竞争 |
| PBFT | 节点间多轮消息协商达成一致 | 许可环境、小中规模节点更典型 |

- 共识机制解决的是分布式参与者如何对账本状态形成一致意见。
- PBFT 类机制通常更适合成员身份受控的联盟链场景；PoW 更常与开放式公有链联系。

⚠️ **易错提醒：** 哈希、数字签名和共识机制作用不同：哈希偏完整性/链式关联，数字签名偏身份认证与不可否认性，共识偏多节点一致。

### 8. 5G 三大典型场景：eMBB、URLLC、mMTC

| 场景 | 中文理解 | 关键词/典型应用 |
|---|---|---|
| eMBB | 增强移动宽带 | 高速率、大带宽、高清视频 |
| URLLC | 超可靠低时延通信 | 低时延、高可靠、工业控制 |
| mMTC | 海量机器类通信 | 海量连接、物联网终端 |

🧠 **速记：** eMBB 看“宽”，URLLC 看“快且稳”，mMTC 看“多”。

- 三者描述的是不同业务需求重点，并非每个 5G 应用同时把三项能力都推到极致。
- MEC 将计算能力下沉到网络边缘，可与 5G 配合降低端到服务处理路径的时延。

### 9. 同态加密与安全多方计算：隐私计算两条典型路线

| 技术 | 核心思想 | 选择题识别 |
|---|---|---|
| 同态加密 | 可直接对密文进行特定计算，解密结果与对明文相应计算具有对应关系 | “密文状态下计算” |
| 安全多方计算（MPC） | 多方共同计算函数，同时尽量不泄露各自私有输入 | “多方协作、不暴露原始输入” |
| 联邦学习 | 数据留在各参与方本地，通过交换模型相关信息协同训练 | “数据不出域、协同训练” |

- 三者都可服务隐私保护，但技术路径不同。
- 联邦学习并不自动消除所有隐私风险，工程中还可结合安全聚合、差分隐私等机制。

📌 **国网考点：** “不解密原始数据即可在密文上完成允许的运算”对应同态加密。

### 10. CPS：信息世界与物理世界形成闭环

**CPS（Cyber-Physical Systems，信息物理系统）**强调计算、通信与物理过程的深度融合。

典型闭环：**感知物理状态 → 网络传输 → 计算分析/决策 → 控制执行 → 再感知**。

- 工业控制、智能制造、智能电网等都是 CPS 的典型应用背景。
- **物联网**侧重“万物连接、感知与数据交换”；**CPS**更强调信息系统对物理过程的实时感知、计算与反馈控制闭环。
- **数字孪生**强调为物理对象建立持续映射的数字模型；它可以与 CPS、IoT 配合，但三者不是同义词。

⚠️ **易错提醒：** CPS 不是单纯的软件仿真，也不是仅把传感器联网。

## 二、国网风格练习题

### 1. 某云平台能够根据业务访问量自动增加或减少计算实例，这最直接体现云计算的哪一特征？

A. 资源永久独占  
B. 快速弹性  
C. 离线计算  
D. 去中心化

**答案：B**

**解析：** 自动随业务负载扩展和收缩资源体现快速弹性。资源池化通常意味着共享与动态分配，不是永久独占；离线计算和去中心化也不是题干描述的云计算特征。

### 2. 下列关于高可用、备份和容灾的说法，正确的是？

A. 只要配置 RAID 就不需要备份  
B. 有数据备份就一定能实现业务无中断  
C. 高可用主要关注减少服务中断，容灾关注重大故障后的业务恢复  
D. 高可用、备份、容灾是完全相同的概念

**答案：C**

**解析：** 高可用强调服务连续性，容灾强调灾难情况下的恢复或持续运行，备份则提供可恢复的数据副本。RAID 不能替代备份，备份也不能自动保证即时业务切换。

### 3. 某系统需要高效表示“用户—关注—用户”的复杂关系，并频繁进行关系路径查询，较适合采用哪类 NoSQL 数据库？

A. 键值数据库  
B. 图数据库  
C. 纯文件存储  
D. 块存储

**答案：B**

**解析：** 图数据库以节点和边表达实体及关系，适合社交网络、知识图谱和路径关系查询。键值数据库更强调按键快速访问值；块存储属于存储服务形态而非这里的数据模型。

### 4. 在发生网络分区的情况下，CAP 理论重点说明分布式系统需要在哪两个性质之间进行权衡？

A. 一致性与可用性  
B. 安全性与性能  
C. 容量与成本  
D. 计算与存储

**答案：A**

**解析：** 在必须容忍网络分区的前提下，系统需要在一致性 C 和可用性 A 之间权衡。常见误区是机械记成任何情况下都只能“三选二”。

### 5. 物联网网关最典型的作用之一是？

A. 只负责生成传感数据  
B. 完全替代所有云平台  
C. 在异构终端与上层平台之间进行协议转换和数据汇聚  
D. 只负责增加无线发射功率

**答案：C**

**解析：** 网关常承担协议转换、数据汇聚、设备接入和一定的边缘处理。传感器负责感知数据；网关并不天然替代云平台，也不是单纯的信号放大器。

### 6. 使用带有“正常/故障”标签的历史设备数据训练故障分类模型，主要属于？

A. 无监督学习  
B. 监督学习  
C. 强化学习  
D. 纯聚类

**答案：B**

**解析：** 已知输入样本及对应类别标签，训练分类模型属于监督学习。聚类通常不使用人工类别标签；强化学习依赖智能体与环境交互及奖励反馈。

### 7. 下列关于 PoW、PoS 和 PBFT 的说法，正确的是？

A. PBFT 的核心是大量哈希算力竞争  
B. PoW 通常通过计算工作量参与竞争  
C. PoS 与权益因素完全无关  
D. 三者都是数据加密算法

**答案：B**

**解析：** PoW 以工作量证明为核心，常伴随算力竞争。PoS 与权益相关；PBFT 依赖节点间消息协商，常见于许可环境。它们属于共识机制，不是加密算法。

### 8. 智能工厂中的无线控制业务特别强调极低时延和高可靠性，最对应 5G 哪一典型场景？

A. eMBB  
B. URLLC  
C. mMTC  
D. SaaS

**答案：B**

**解析：** URLLC 的关键词是超可靠、低时延，适合工业控制等业务。eMBB 侧重增强移动宽带，mMTC 侧重海量机器连接，SaaS 是云服务模型。

### 9. “允许在不先解密原始数据的情况下直接对密文进行特定运算”最符合哪项技术？

A. 同态加密  
B. 网络切片  
C. RAID  
D. 对象存储

**答案：A**

**解析：** 同态加密的典型识别点就是密文计算。网络切片用于逻辑网络资源隔离与定制；RAID 是磁盘阵列技术；对象存储是存储服务形态。

### 10. 下列哪一项最能体现 CPS 的典型闭环特征？

A. 只把历史数据长期归档  
B. 感知物理状态、计算决策并反馈控制物理过程  
C. 只建立静态网页  
D. 只在数据库中保存设备名称

**答案：B**

**解析：** CPS 强调计算、通信与物理过程融合，通过感知—计算—控制形成反馈闭环。仅归档数据或建立静态信息系统不能体现其核心特征。

### 11. 【间隔复习】下列关于 Serverless 的说法，正确的是？

A. Serverless 表示物理上完全不存在服务器  
B. 开发者必须手工管理每台底层服务器  
C. 平台通常负责更多资源调度、伸缩等底层管理工作  
D. Serverless 只能用于数据库

**答案：C**

**解析：** Serverless 并非没有服务器，而是由平台承担更多服务器和资源管理职责，开发者更聚焦业务逻辑。它可用于事件处理、API 等多种场景。

### 12. 【间隔复习】关于 Spark 和 Flink，下列说法较准确的是？

A. Spark 只能处理单机文件  
B. Flink 只能进行离线批处理  
C. Spark 是通用分布式处理引擎，Flink 的流处理能力尤其突出  
D. 二者都属于区块链共识机制

**答案：C**

**解析：** Spark 以通用分布式计算和内存计算著称，也支持流处理；Flink 在有状态流处理方面定位突出，也支持批处理。不能把二者机械限定为单一处理模式。

### 13. 【间隔复习】企业知识库频繁更新，希望大语言模型回答问题时先检索最新内部资料再生成答案，较适合采用？

A. RAG  
B. RAID  
C. NFV  
D. PBFT

**答案：A**

**解析：** RAG 先检索外部知识，再把相关上下文提供给模型辅助生成，适合知识库持续更新的场景。RAID、NFV、PBFT 分别属于存储、网络功能虚拟化和共识领域。

### 14. 【间隔复习】“控制平面与数据平面分离，并通过可编程控制器集中实施网络策略”主要描述？

A. SDN  
B. NFV  
C. NFC  
D. HDFS

**答案：A**

**解析：** SDN 的经典考点是控制平面与数据平面分离以及网络可编程。NFV 强调把传统专用网络设备功能以软件方式运行在通用硬件上，两者可协同但不是同义词。

### 15. 【间隔复习】下列关于容器和虚拟机的说法，正确的是？

A. 每个容器通常都必须运行完整独立的 Guest OS 内核  
B. 容器通常共享宿主机内核，因此相较完整虚拟机更轻量  
C. Kubernetes 是一种 CPU 指令集  
D. Docker 的核心定位是关系数据库

**答案：B**

**解析：** 容器通过操作系统级隔离，通常共享宿主机内核；虚拟机一般包含独立 Guest OS，因此容器往往启动更快、资源开销更小。Kubernetes 用于容器编排，Docker 与容器构建/运行生态相关。
