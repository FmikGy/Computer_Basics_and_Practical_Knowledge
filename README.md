# Computer Basics and Practical Knowledge

> 面向国家电网计算机类考试的「计算机基础与实用知识」每日晨练仓库。

本仓库用于补充 **408 + 数据库 + 软件工程** 之外，国网计算机考试中常见但容易被忽略的基础与实用类知识点。内容以“**见过即可拿分**”为目标，强调高频常识、历史教材口径、易混淆点和国网风格选择题。

## 仓库定位

主要覆盖以下内容：

- **PC 硬件与微机基础**：CPU、主板、芯片组、北桥/南桥、BIOS/CMOS/UEFI、内存、存储、总线、PCI/PCIe、常见接口与外设
- **Windows / DOS 基础**：注册表、文件类型、系统组件、常用命令、批处理等
- **Linux / UNIX 实用基础**：文件类型、目录结构、用户与组、权限、Shell、文本处理、进程、网络与系统管理命令
- **计算机网络标准常识**：IEEE 802 系列、Ethernet、Wi-Fi、Bluetooth、WiMAX 等
- **文件格式与编码**：常见扩展名、字符编码、压缩与归档格式等
- **多媒体与计算机应用基础**：图像、音频、视频、常见格式及基础概念
- **国网老题常见历史知识**：北桥/南桥、MMX、传统 BIOS/CMOS、经典总线与接口等

## 每日内容结构

每天生成一个独立 Markdown 文件，文件名格式：

```text
YYYY-MM-DD.md
```

每份内容通常包含：

1. **今日主题 / 今日目标**
2. **今日知识点**
   - 核心定义与作用
   - 常见分类、版本与演进
   - 国网常见考法
   - 易混淆点
   - 必要的表格、口诀、命令示例
3. **国网风格练习题**
   - 每天约 10～15 道单选题
   - 每道题后立即给出答案与解析
4. **今日速记**
   - 关键标准号
   - 对应关系
   - 高频命令
   - 易错对比

## 示例：知识点不是只记结论

例如 IEEE 802.11，不仅记：

```text
802.11 = 无线局域网 WLAN
```

还会继续扩展：

| 标准 | 常见频段 | 典型特点 | Wi-Fi 代际 |
|---|---|---|---|
| 802.11a | 5 GHz | 早期 OFDM | - |
| 802.11b | 2.4 GHz | 速率较低 | - |
| 802.11g | 2.4 GHz | 兼容 b，速率提升 | - |
| 802.11n | 2.4 / 5 GHz | MIMO | Wi-Fi 4 |
| 802.11ac | 5 GHz | 更宽信道、MU-MIMO | Wi-Fi 5 |
| 802.11ax | 2.4 / 5 GHz（6 GHz 对应 Wi-Fi 6E） | OFDMA、高密度优化 | Wi-Fi 6 |
| 802.11be | 2.4 / 5 / 6 GHz | MLO、更高吞吐 | Wi-Fi 7 |

目标是既能应付“**802.11 是什么标准**”这类基础题，也能识别 a/b/g/n/ac/ax 之间的常见差异。

## 学习建议

本仓库不适合替代 408、数据库或软件工程的系统学习，更适合作为国网计算机备考中的 **查漏补缺与考前速记资料**。

推荐使用方式：

- 每天先看当日知识点
- 再做当日选择题
- 错题立即回看对应知识点
- 每隔几天回顾一次“今日速记”
- 遇到老题时，注意区分“**传统教材答题口径**”和“**现代技术实际情况**”

> 例如：北桥/南桥属于传统 PC 架构，现代平台中很多北桥功能已经集成进 CPU，但老题通常仍按传统教材知识作答。

## 更新方式

仓库按天持续更新，每天新增一份晨练 Markdown 文件，并采用：

- **专题轮换**：避免连续多天重复相同主题
- **间隔复习**：旧知识会在后续习题中滚动出现
- **逐步扩展**：知识点正文持续扩大覆盖面
